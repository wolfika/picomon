# Writing style

Plain, direct, pragmatic prose. The reader is competent in the subject. State each concept once, at the level a colleague would use.

# State things positively

Describe what something is, does, or costs. Rewrite “not X but Y”, “it’s not X, it’s Y”, and “less about X, more about Y” as a direct statement of Y. State a boundary once, as a fact.

# Say it once

Each fact, decision, and justification appears once, in the place it belongs. Refer back to it instead of repeating it. Omit closing summaries and sentences that explain what a section just showed.

# No rhetorical reinforcement

State a claim once, in plain words. Omit “it’s important to note”, “crucially”, “the bottom line”, “this is exactly why”. Omit rhetorical questions, scene-setting openers, and items grouped in threes for rhythm. Leave the conclusion to the reader.

# No selling

Neutral register. Omit superlatives, aspirational framing, and words such as “powerful”, “seamless”, “game-changing”, “unlock”, “leverage”, “delve”, “landscape”, “testament”, “showcase”, “pivotal”, “vibrant”. State facts without assigning significance, legacy, or broader trends to them.

# Structure

Each section depends only on earlier sections. Two or three heading levels at most.

# Density

Short sentences, one idea each. Omit sentences that only transition. Use lists for parallel, enumerable items and prose when the relationship between ideas carries meaning.

# Tone

Neutral and factual. Omit enthusiasm, reassurance, and politeness hedging.

# Test

Draft the text, then remove every sentence whose removal costs the reader no information, and halve any section that can be halved without loss. Return the shortened text.
